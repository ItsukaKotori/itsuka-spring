# 网关访问说明

## 基础信息
- 网关地址：`http://localhost:8888`
- 统一鉴权：请求头 `Authorization: Bearer <accessToken>`（认证、文档、健康检查等排除路径无需）
- CORS：全局允许跨域（来源/方法/头均为 `*`，支持凭证）
- 文档入口：`/swagger-ui/index.html`、`/v3/api-docs`

## 路由映射
- 系统模块（itsuka-system）
  - 路由前缀：`/api/system/**`
  - 目标服务：`http://localhost:8081`
  - 过滤器：`StripPrefix=2`（移除 `/api/system`）
  - 访问示例：
    - `GET /api/system/api/users/profile` → 系统服务 `GET /api/users/profile`
    - `POST /api/system/api/auth/login` → 系统服务 `POST /api/auth/login`
    - `POST /api/system/api/users/avatar` → 系统服务 `POST /api/users/avatar`

- 音乐模块（itsuka-music）
  - 路由前缀：`/api/music/**`
  - 目标服务：`http://localhost:8082`
  - 过滤器：`StripPrefix=2`（移除 `/api/music`）
  - 访问示例：
    - `GET /api/music/api/songs/{id}` → 音乐服务 `GET /api/songs/{id}`
    - `POST /api/music/api/playlists` → 音乐服务 `POST /api/playlists`

- 文档路由（聚合）
  - 路由前缀：`/swagger-ui/**`, `/v3/api-docs/**`
  - 目标服务：`http://localhost:8080`

## 鉴权与访问控制
- JWT 认证
  - 配置项：`itsuka.security.jwt.secret/expiration/issuer`
  - 排除路径：`itsuka.security.auth.excluded-paths`
    - 默认包含：`/api/auth/**`, `/actuator/**`, `/swagger-ui/**`, `/v3/api-docs/**`, `/error`

- 访问控制（黑/白名单）
  - 配置项：`itsuka.security.access-control.*`
  - 支持：路径（Ant）、IP（CIDR）、User-Agent（通配符）
  - 执行顺序：访问控制 → 认证 → 业务

- 限流
  - 过滤器：`RateLimitFilter`
  - 依赖：`spring.data.redis.*`（可选）
  - 维度：IP/用户维度

## 常见错误响应
- 格式统一（示例）
```json
{
  "code": 403,
  "message": "Access denied",
  "timestamp": 1673616000000,
  "path": "/api/system/api/users/profile",
  "status": "Forbidden"
}
```

## 使用示例
- 登录获取令牌（系统服务经网关）
```bash
curl -X POST \
  http://localhost:8888/api/system/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"itsuka","password":"Pass123"}'
```

- 带鉴权访问用户资料
```bash
curl -X GET \
  http://localhost:8888/api/system/api/users/profile \
  -H 'Authorization: Bearer <accessToken>'
```

- 上传头像（multipart）
```bash
curl -X POST \
  http://localhost:8888/api/system/api/users/avatar \
  -H 'Authorization: Bearer <accessToken>' \
  -F 'file=@/path/to/avatar.png'
```

- 获取音乐列表
```bash
curl -X GET \
  http://localhost:8888/api/music/api/songs?page=1&size=20 \
  -H 'Authorization: Bearer <accessToken>'
```

## 配置参考
- 核心配置文件：`itsuka-gateway/src/main/resources/application.yaml`
- 关键段落：
  - 路由：`spring.cloud.gateway.routes`
  - CORS：`spring.cloud.gateway.globalcors`
  - 默认过滤器：`spring.cloud.gateway.default-filters`
  - JWT/访问控制：`itsuka.security.*`

## 注意事项
- 路径映射说明：由于 `StripPrefix=2`，经网关访问时需要在业务路径前增加模块前缀，例如系统模块需使用 `/api/system/` 前缀；去除前缀后保持原服务的 `/api/**` 路由结构
- 生产环境：请按实际部署地址调整各模块 `uri`，并配置强度足够的 JWT 密钥与访问控制策略
