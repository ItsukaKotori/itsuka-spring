# Itsuka-Spring

#### 介绍
Starter合集

#### 软件架构

##### common - 基础依赖, 包含core及各类starter
##### -- itsuka-core - 核心依赖, 定义统一响应, 统一用户实体类, 异常体系, 常量及枚举
##### -- itsuka-dict-spring-boot-starter 字典翻译Starter
##### -- itsuka-mybatis-spring-boot-starter Mybatis Starter
##### -- itsuka-redis-spring-boot-starter Redis Starter
##### -- itsuka-web-spring-boot-starter Web Starter
